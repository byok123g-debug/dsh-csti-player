# 省钱模式（Frugal mode）

一个常驻的「输出纪律」插件。它不改变任何业务逻辑，只在每次组装系统提示时追加一节规则。

## 它做三件事

1. **限制回复长度**：`replyMaxLines`（默认 12 行），并要求先结论后细节、不复述工具输出、不逐步解说。
2. **限制截图张数**：`imageBudget`（默认每轮 2 张），要求先查缓存坐标再决定是否截图。
3. **内建坐标表**：把《卡牌生存》2560×1599 下常用落点写成文本常驻在提示里，用几百 token 替掉每次约 2.6k token 的截图。

## 配置

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 关掉后整节规则不注入 |
| `replyMaxLines` | `12` | 回复行数上限（软约束） |
| `imageBudget` | `2` | 每轮允许的截图张数（软约束） |
| `coords` | `''` | 追加任意坐标笔记，原样拼进提示 |

## 已知限制

- 这一版是**提示层**约束，不是运行时硬拦截：它让模型少说少截，但不会拒绝工具调用。
- 硬拦截（真·拒绝超额截图）和图像降采样需要 `tools` 拦截器与图像库，留待下一版。
- 坐标表是给特定游戏写的；换场景时改 `coords` 或关掉 `enabled`。
